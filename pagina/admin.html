Guía de implementación rápida

Opción A — Zapier: Crea un Zap con trigger "Webhook → Catch Hook" y acción "Gmail / Slack / Google Sheets".
Opción B — Make (Integromat): Escenario con módulo Webhook + Gmail/Twilio. Ideal para WhatsApp vía Twilio.
Opción C — n8n (local): Instala n8n, crea un workflow con Webhook node y conecta Gmail + Google Sheets. Totalmente gratuito.
Opción D — Base de datos local: Todos los datos se guardan en localStorage y se exportan como CSV desde la pestaña Equipos.
